## Upgrade notes

Moves every Unique image and the release-locked Conduct charts (`assistants-core`,
`sbx-gateway`, `sbx-templates` and its Fargate variant `sbx-templates-fargate`) from
`2026.42.10` to `2026.46.0`. This skips four releases: `2026.44.0`, `2026.44.1`, `2026.44.2`
and `2026.44.3`.

The generic `backend-service` (10.5.1) and `web-app` (5.3.0) charts are unchanged — those are
the newest published, so for every service on them this release moves the image tag only. The
four release-locked charts above move with the release, as they always do.

### Configuration

**No new required instance values.** Everything the services gained in this window is optional
or defaulted, and no key this repository sets was renamed or removed.

| Where | Change | Effect |
|---|---|---|
| none | `ACTIVITY_RECORDS_MAX_DATA_SIZE_BYTES` (1 MiB) and `ACTIVITY_RECORDS_MAX_BATCH_SIZE_BYTES` (8 MiB) | New operator-facing limits on activity-record events. Oversized metadata is truncated rather than the event being dropped. Both are defaulted; set them only to change the limits |
| none | `FEATURE_FLAG_ENABLE_CONDUCT_MODEL_SELECTION_UN_26651` | Off by default. Lets an admin offer model switching and per-model reasoning effort on a Conduct space's harness card |
| none | `FEATURE_FLAG_LANGUAGE_SETTINGS_UN_24630` | Off by default. German and French interface language in Admin, Knowledge Upload and Theme |
| none | `FEATURE_FLAG_DUPLICATE_SPACE_AS_DRAFT_UN_25922` | Off by default. Duplicating a space creates an unpublished draft |

None are added to `defaults/`: they are off upstream, and `defaults/` is shared by every
environment that adopts a release, so a flag belongs there only when the fleet should take it
together.

### The benchmarking model alias still applies

`ContradictionComparisonService` still constructs a client for `AZURE_GPT_4o_2024_1120` during
`onApplicationBootstrap`, so chat does not start unless LiteLLM serves a model by that name.
This was checked against the source at `2026.46.0`, where the reference count rose from 68 files
to 70 rather than falling.

The `gpt-4o-2024-11-20` entry in `value-overlays/litellm/litellm.yaml`, aliased to Claude Opus
5.5, therefore stays. Do not remove it as part of this upgrade.

### Model migrations upstream

This release migrates retired Gemini models to Gemini 3.8 Flash and Claude Sonnet 4.5 to Sonnet
5 in node-chat. Neither is in this deployment's fleet, which serves Claude Opus 5.5 and the
three GPT-6 tiers, so no LiteLLM change is required. An installation that serves Gemini or
Sonnet 4.5 should check its own `model_list` before upgrading.

### Rendered output reviewed

The structured upstream changelog stops at `2026.44.3`: there are no `.changelog/2026.46.0/`
entries, so the operator-facing notes above come from the `2026.44.x` releases and from reading
the `2026.44.3..2026.46.0` commit range, which is 742 commits. Because that is a wider window
than a single release, the four release-locked charts were additionally rendered at both
versions against this environment's own value files and diffed.

| Chart | Difference beyond the chart and version labels |
|---|---|
| `assistants-core` | Fourteen entries added to the model pricing catalog and two removed (`deepseek-v4-pro`, `llama-3-3-70b-instruct-turbo`, neither served here); a `coordination.k8s.io` `leases` RBAC rule for leader election; two feature-flag keys dropped from the rendered ConfigMap |
| `sbx-gateway` | A deployment env checksum. The `egress-mitm-ca` Secret also differs, but the chart mints that per render — `apps/conduct/sbx-gateway.yaml` already pins it with `ignoreDifferences` |
| `sbx-templates`, `sbx-templates-fargate` | None |

The two dropped keys are `FEATURE_FLAG_ENABLE_ELICITATION_UN_15809` and
`FEATURE_FLAG_ENABLE_NEW_ANSWERS_UI_UN_14411`. Neither is set by this repository — both came
from the chart's own defaults, both were `"true"`, and both features are now unconditional. The
rendered ConfigMap loses two keys and behaviour is unchanged.

Nothing in the diff requires a configuration change, which is what the section above states.
